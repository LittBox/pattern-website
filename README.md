# 云纹潮生——云南15个世居少数民族纹样小程序技术需求文档

> 文档版本：v1.0  
> 项目类型：微信原生小程序  
> 数据方案：静态资源 + JSON 索引 + 民族独立 JSON 文件  
> 核心目标：让云南15个世居少数民族传统纹样“可看、可读、可检索、可分享、可扩展”

---

## 1. 项目概述

本项目是一款以云南15个世居少数民族传统纹样为核心内容的文化展示类微信小程序。

项目面向民族文化爱好者、设计师、研究者、高校师生及大众用户，提供民族纹样分类浏览、高清图片展示、纹样文化解读、关键词检索、收藏分享、AR/3D 扩展入口等功能。

本版本技术方案以“静态数据”为核心，不使用云数据库存储纹样基础信息。所有民族、纹样、图片说明、文化解读、AR 链接等内容均通过本地或远程静态 JSON 文件管理。

---

## 2. 技术方案说明



### 2.1 本版本采用


- 静态 JSON 数据文件
- 静态图片资源
- JSON 总索引文件
- 每个民族单独一个 JSON 文件
- 图片对象中包含对应图片的基本信息与文化描述



### 2.3 图片资源策略

由于项目包含 800 余幅高清纹样图片，因此图片不建议全部打入小程序主包，应采用以下策略：


- 纹样高清图作为静态资源，通过 JSON 中的 URL 或相对路径引用
- 如果必须完全离线展示，则需要按民族拆分资源包，并严格控制图片体积
- 图片需要生成缩略图与高清图两套资源

## 3. 项目范围

### 3.1 MVP 必须实现

| 模块 | 是否必须 | 说明 |
|---|---:|---|
| 首页 | 必须 | 展示项目介绍、视觉封面、入口按钮 |
| 民族分类页 | 必须 | 展示 15 个民族入口 |
| 民族纹样列表页 | 必须 | 按民族展示纹样图片列表 |
| 纹样详情页 | 必须 | 展示单张图片、名称、民族、寓意、来源、用途等 |
| 静态 JSON 数据系统 | 必须 | index.json + 每民族一个 JSON 文件 |
| 图片懒加载 | 必须 | 保证大量图片列表滑动流畅 |
| 搜索功能 | 必须 | 支持按民族、纹样名称、关键词搜索 |
| 分享功能 | 必须 | 支持分享小程序页面 |
| 图片预览 | 必须 | 点击查看大图 |

### 3.2 V1 可选实现

| 模块 | 是否必须 | 说明 |
|---|---:|---|
| 收藏功能 | 可选 | 使用本地缓存保存收藏 |
| 中英文切换 | 可选 | JSON 预留英文段落 |
| 文创预览 | 可选 | 用纹样生成包装、服饰、海报预览 |
| 数据校验脚本 | 推荐 | 检查 JSON 字段、图片路径、ID 是否重复 |

## 4. 目标用户

### 4.1 普通浏览用户

用户可以快速了解 15 个云南世居少数民族纹样，浏览高清图片，阅读纹样背后的文化含义。

### 4.2 设计学习者

用户可以按民族、纹样类型、关键词查找纹样，用于视觉设计、文创设计、包装设计、服饰设计参考。

### 4.3 毕设展示场景

项目可作为毕业设计作品进行展示，强调“文化内容 + 视觉设计 + 小程序交互 + AR 扩展”的完整性。
